# DIRETO — site

Proposta comercial da DIRETO (reserva direta para hotéis e pousadas
independentes) como página única, pronta pra mandar o link.

Sem build, sem dependência — é HTML puro com fontes do Google Fonts.

## Estrutura

| Arquivo | O que é |
|---|---|
| `index.html` | O site inteiro |
| `og-image.png` | Imagem de preview pra quando o link é colado no WhatsApp/redes |

## Publicado em

https://gabrielbrambillamkt-sketch.github.io/direto-hotelaria/

## Editar

Abre `index.html` direto no navegador pra ver local, ou usa a extensão Live
Server no VS Code. Depois de editar: `git add . && git commit -m "..." && git push`
— o GitHub Pages atualiza sozinho em 1-2 minutos.
